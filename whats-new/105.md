- **Git Dash:** Automatic refresh is off by default. Use the Refresh button in the middle of either tab to load its first results. Worktrees also shows this button when its saved list is empty. Use the toolbar to refresh a populated list, or turn on Automatic refresh in PowerMods settings.
- **Dock and Kanban:** The Git button opens one panel with Repository, Dashboard and Pull requests, in the dock or in a dialog. The Dashboard loads when you select it.
