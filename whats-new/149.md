- **PowerMods (Command Palette):** Every panel, tool and action mod now registers its commands in Herdr's Command Palette under the **PowerMods** group.
- **files-md:** Markdown editing now highlights syntax with theme colors, uses 2-space tabs, and adds a live **Wrap** toggle; Markdown previews now include in-document search (**Find** / `Ctrl/Cmd+F`) with match highlighting, text selection actions (**Copy Markdown** and **Send to terminal**), safe HTML rendering, mouse back/forward navigation, and Ctrl/Cmd-clicking Markdown paths (including `:line`) in terminals.
- **spec-board:** Markdown editing now highlights syntax with theme colors and adds a live **Wrap** toggle; spec previews now support in-document search (`Ctrl/Cmd+F`) with match highlighting, text selection actions (**Copy Markdown** / **Send to terminal**), safe HTML rendering, and mouse back/forward navigation.
- **image-viewer:** Added a native file picker (**Open…**) supporting multiple images with next/previous navigation, plus Ctrl/Cmd-clicking image paths in terminals.
- **quick-actions & automations:** Added native **Choose…** file pickers for scripts and prompt files, and mouse back/forward navigation between list and detail views.
- **issues & prs:** Markdown descriptions and comments now support safe HTML rendering and text selection actions (**Copy Markdown** / **Send to terminal**), mouse back/forward navigation, and a floating **↑ Top** button when scrolling long lists.
- **tabs-dock, space-deck, git-client & visual-review:** Dragging tabs, cards, commit graph columns, canvas pan and split panes now tracks the pointer across the entire window; **tabs-dock** shows left/right overflow buttons when tabs exceed the bar width, and **git-client** History and **ci-dash** Runs show a floating **↑ Top** button when scrolled down.
- **main-dock & kanban:** Added accent hover highlights on resizable dividers, subtle focus dimming on unfocused panes, and terminal link handlers for **image-viewer** and **files-md**.
- **All mods:** UI polling timers now pause while the Herdr window is hidden, and pressing `Esc` in an empty docked search box cleanly releases keyboard focus back to the terminal.
