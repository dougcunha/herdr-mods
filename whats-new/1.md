The first version with a version number. It holds all the mods, layouts and themes of this repository:

- **dock-app:** the `main-dock` layout, with side-panel buttons from `dock/panels.json`, and the `files-md` mod, which opens Markdown files and images in a viewer.
- **kanban-app:** the `kanban` layout, where every agent is a card in a column by status. The git panels are under 1 **Git** button with a menu.
- **ci-dash-app:** the `ci-dash` panel with the GitHub Actions runs of the repository that you work in.
- **git-dash-app:** the `git-dash` panel with the pending work of every Git repository under one base folder.
- **changes-app:** the `changes-split` mod, the Changes panel with a **Unified / Split** switch for a side-by-side diff.
- **image-viewer-app:** the `image-viewer` mod, which shows 1 image file with zoom from 10% to 800%.
- **agent-resume-app:** starts your Claude Code, Codex, Antigravity and OpenCode sessions again after a reboot of the computer or a restart of herdr-core.
- **repo-launcher-app:** press `Ctrl+P` to open a repository with a terminal or an agent.
- **light-themes-app:** 5 light themes.
- **dark-themes-app:** 6 dark themes with lighter backgrounds.
- **mods-update-app:** this status bar item. It tells you when a new version of the mods is available and starts an agent that updates them.
