- **files-md:** the right-click menu has edit items: New file, New folder, Cut, Copy, Paste, Duplicate, Rename and Delete. Rename and New ask for the name in the menu. Delete asks first; on Windows the item goes to the Recycle Bin. Right-click the empty area below the rows to make a file or a folder in the root folder.
- **files-md:** a filter field at the top of the Files panel finds any file or folder of the project with a fuzzy match, for example `rdm` for `README.md`. The field has the keyboard when the panel opens. ↑/↓ pick a result, Enter opens it, Esc clears the field. In the preview of a file, Esc goes back to the tree or the results. In a Git repository it does not show ignored files.
- **files-md:** a click on an image shows it in the panel preview, like Markdown and code: fit to the panel, or zoomed from 10% to 800% with the zoom bar in the header (**Fit**, **100%**, **−**, **+**), the keys `+`, `-`, `0` and `F`, or Ctrl + mouse wheel. The header shows its size. To open the image beside the terminal, right-click it and choose **Open in Image Viewer**.
- **files-md:** the right-click menu now opens at the click when the Files panel is a dialog. Before, it opened near the button that opened the dialog.
- **Esc in dialogs:** Esc now closes every panel dialog of the dock (tabs-dock and kanban). Before, the terminal behind the dialog kept the keyboard and got the Esc. Esc works also after a click inside the Files, Changes, Pending and CI Runs panels, and inside Insights and Graph (the update adds a small patch to the third-party `insights` and `git-graph` mods; not in the Settings view of Insights). In Graph, Esc first closes a diff or the details, as before. Esc also closes a dialog when a text field has the keyboard. In a filter field (Files, Pending, CI Runs), the first Esc clears the text and the next Esc closes the dialog. In the commit message of Pending, Esc cancels the commit. In Changes, Esc closes the dialog when the commit message is empty. Esc also closes the Herdr Mods dialog from a settings field, the Repo Launcher from an argument field, and the name step of the Files menu.
