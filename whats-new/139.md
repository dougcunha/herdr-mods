- **quick-actions:** An action can run in the background, with no terminal on the screen: **Where it runs**, **Background**. A toast shows when it ends. The list shows the state of the last run of each action; a click shows its output, and **Stop** stops it.
- **quick-actions:** A new setting, **Background timeout** (30 min by default), stops a background run that waits too long, for example for a password.
