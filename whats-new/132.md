- **quick-actions:** **New with an agent…** in the form of a script file: write what the script must do, choose an agent and click **Start**. The action is saved, and the agent writes the script in a new tab. **Edit with an agent…** changes a script that exists. The **Script folder** setting sets where new scripts go.
- **quick-actions:** `{ask:Label}` and `{ask:Label=default}` in a script ask for a value before the run. The question shows 1 field for each label and the script with your answers.
