- **git-client:** the right-click menu of a file that Git tracks, in the **Changes** tab, has **Stop tracking…**. It removes the file from Git and keeps it on disk, then adds it to `.gitignore` or to `.git/info/exclude`. The removal is staged: the next commit deletes the file from the repository.
- **git-client:** the right-click menu of an untracked file has one **Ignore…** item, in place of **Add to .gitignore** and **Add to .git/info/exclude**. Its dialog asks what to ignore: the file, every file with its extension, or one of the folders of the file. **Only on this machine** writes to `.git/info/exclude`.
