- **powermods-core:** new required mod. It makes the git worktrees of the kit in 1 folder (`~/.herdr/worktrees/<repository>/<branch>` by default; change it in Settings) and runs 1 setup for each new worktree: files to copy (a files folder of yours, and the git-ignored files that `.herdr/worktree.json` or `.worktreeinclude` name), then commands (yours, and the repository's after you say yes) in a "setup" tab. Its `worktrees` item in the status bar shows the setups that run and opens their output.
- **issues, prs:** Start agent makes the worktree through PowerMods Core. The agent starts when the setup ends well.
- **spec-board:** Start in worktree makes the worktree through PowerMods Core. The Worktree folder setting moved to PowerMods Core; your old value still applies until you set the new one.
- **git-client:** New worktree goes to the folder of PowerMods Core (not next to the repository any more), with its setup. It uses the branch when it exists (also one only on `origin`), else it makes a new one from HEAD: the "Create the branch" check is gone. Remove worktree also closes a space that works only in that folder.
- **git-dash:** Remove worktree goes through PowerMods Core.
- **mods-hub:** the Mods tab shows a mod that other mods need without an on/off switch.
