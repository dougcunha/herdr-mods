- **mods-hub:** the dialog now tells you when GitHub has a newer version of a third-party mod (`git-graph`, `markdown-reader`, `markdown-reader-pane`, `insights`). It asks GitHub once a day for the last commit of each mod's folder. The **Third-party** list of the **Mods** tab shows an **update** pill, the installed and the newest commit, the files that are not as on GitHub (the kit's patches or your changes), and the buttons **Update with an agent**, **Compare on GitHub** and **Open on GitHub**. The status bar shows `↑N` next to `mods vN` when N third-party mods have an update.
- **mods-hub:** **Update with an agent** starts the agent that you choose with only the new "Update a third-party mod" section of the setup prompt: it backs up the mod, asks before it replaces a file that you changed, applies the kit's Esc patches again and records the new version.
- **Setup:** this run records the version of each third-party mod that is installed, so the check works from now on. Mods that were not recorded show "Version not recorded" and an **Update and record with an agent** button.
