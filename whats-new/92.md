- **skill-bundles:** Skills of other repositories are back, as links. A `sources:` entry of `skills.yaml` can name any repository of skills (`owner/repo` or a Git URL). The mod keeps one clone of that repository in its cache and links the skills to it. The panel shows a group for each repository.
- **skill-bundles:** A skill of another repository never changes without your action. The mod only fetches: the group title says how many new commits the remote has, and **Update** brings the clone to the remote for all your projects.
- **skill-bundles:** **Another repository** is back in **Add skill**: write a repository, click **List skills**, then **Link** one skill. Without a Catalog, **Add skill** opens this view.
- **skill-bundles:** Copies that `npx skills` installed from other repositories now change to links too.
- **skill-bundles:** `link-skills.mjs` in a terminal clones the repositories of `sources:` when they are not there (`--sources <dir>`).
