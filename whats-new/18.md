- **skill-bundles:** a new mod for the agent skills of a project. It compares the skills of the focused project with your skill Catalog (a repository with a `bundles.yaml`, read through the `skills.yaml` of the project) and shows each skill as up to date, outdated, missing, extra or local. Buttons start a project (choose the Bundles; the mod writes `skills.yaml` and installs), update all, change the Bundles, add one skill, and remove or keep an extra skill. It runs `npx skills`, so it works on Windows and macOS without PowerShell.
- **skill-bundles:** a status bar item shows `skills ✓`, or the number of skills that ask for action; a click opens the panel. The **Skills** button of the Dock opens the same panel. Write your Catalog (`owner/name`) in Herdr Mods → **Settings** → **Skill Catalog**.
