- **skill-bundles:** **Add skill** can now install a skill from any repository of skills. Write `owner/repo` (or a Git URL) and click **List skills**: the panel shows the skills of that repository with their descriptions, each with an **Install** button. In a project with a `skills.yaml`, the view is behind **Another repository** in **Add skill**, and **Keep in skills.yaml** adds the skill to `sources:`.
- **skill-bundles:** A problem of your own clone of the Catalog now stops only an install from the Catalog, not from other repositories.
