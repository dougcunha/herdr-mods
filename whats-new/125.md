- **github-clone:** New mod **GitHub Clone** (`Alt+G`, or **Clone** in the Dock bar): lists the GitHub repositories of the `gh` account of this computer or of another machine, with owner chips, an Archived chip, a fuzzy search and a sort order. Pick one, check the folder, the branch and the shallow switch, and it clones in a terminal of a new space on that machine. `Ctrl+O` opens the repository on GitHub. Set a clone folder for each machine, and owner rules, with the gear of the dialog.
- **repo-launcher:** A GitHub button in the header opens GitHub Clone, when that mod is installed. A new clone shows in the list at once.
