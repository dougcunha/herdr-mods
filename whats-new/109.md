- **issues:** The Description and the long extra fields (such as Refinement) of an issue page now have a **Show full text** button when the text is long. It shows the whole text in the tab, and **Show less** goes back to the start. Before, the text stopped after about 2,000 characters and you had to open Jira.
- **issues:** **Move** now asks for the fields that a Jira workflow requires on a move (for example **Fix versions** or **Resolution**) in a small form, instead of failing with an error.
- **issues:** New **Fix version…** action in the right-click menu of the Jira list, and a click on the **Fix versions** row of the issue page, to set the Fix versions from a list of the project versions, with a box that filters the list by text.
