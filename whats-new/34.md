- **issues-app:** new. 2 Dock panels: **Issues** shows the issues of the space from Jira Cloud or GitHub, and **PRs** (in the Git menu) shows its pull requests. Each item opens as a page, with a button that starts an agent on it in a new worktree. A copy of Herdr Ranch by Jelle Slowack.
- **issues-app:** the settings **Order** and **Page** are in the **Settings** tab of Herdr Mods. The settings that you made in Herdr Ranch move over.
- **issues-app:** **Extra Jira fields** in the Settings tab: Jira custom fields (for example Refinement) go into the Start agent prompts, each as its own placeholder and all together in `{fields}`, and show on the issue page.
- **issues-app:** Start agent can run the agent in a new tab of an open space, on its current branch, instead of a new worktree. The dialog shows the repository, and the Default model and effort of the agent. It opens at once with the agents that it found before (↻ checks again), each with the icon of its provider.
- **issues-app:** **Move** on a Jira issue page lists the moves of its workflow and moves the issue to the status that you pick. The list and the page reload after the move.
- **issues-app:** on Windows, **Connect** in **Link space** stores the Jira token without the error "The credential store refused it".
