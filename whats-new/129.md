- **quick-actions:** New mod. Keep named scripts and run them in the terminal of the shown space: `Alt+Q` opens the list, type a part of the name and press Enter. Write the script in the form or use a `.ps1` or `.sh` file. Variables such as `{repo}`, `{branch}` and `{space}` get their values from the terminal, in quotes. When the terminal runs an agent or a program, the action opens a new tab in the same folder. An action can ask before it runs, and can run only in some folders or repositories. Give an action its own key with `quick-actions.run-<id>` in `keys.json`.
