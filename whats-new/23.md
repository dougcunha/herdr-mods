- **automations:** a new mod that runs a coding agent with a prompt in a folder. A run starts on a schedule (every N minutes, daily, days of the week or cron), with **Run now**, when an agent is done or needs you, when files in the folder change, or on a new commit or branch. The agent runs headless (its output goes to the history) or in a tab that you can follow.
- **automations:** a check script can skip a run, a pre-script gives context to the prompt (`{pre}`), and a post-script gets the status and the result file that the agent wrote (`{result_file}`). Each run has its own folder, so 2 runs never share a file.
- **automations:** the status bar item `automations` runs the automations and opens the dialog: the list, a form with tabs, and the history of the last 50 runs of each automation with the output of every step. A Dock button **Automations** shows the same dialog as a panel.
