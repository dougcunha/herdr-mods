- **issues-app:** the page of a Jira issue has a new **Attachments** tab when the issue has files. **Download** saves one file and **Download all** saves every file into `.jira/<issue key>/` in the folder of the shown space. For an archive (`.zip`, `.tar.gz` and the like; on Windows and macOS also `.7z` and `.rar`), **Extract** also extracts it into a folder with its name. The mod does not change `.gitignore`: add `.jira/` to it when you do not want Git to show the folder. The downloads work only for a space on this computer.
