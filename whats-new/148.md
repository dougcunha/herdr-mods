- **git-client:** The Branches tab now supports selecting multiple local and/or remote branches (left-click a branch or its checkbox, `Shift+Click` for ranges, or `Ctrl/Cmd+A`, with right-click for the context menu) to delete them together from the selection bar or context menu.
- **git-client:** The **New worktree** dialog (`+` on Worktrees) now lets you pick an existing local or remote branch (filtered by All/Local/Remote) or create a new branch starting from `HEAD` or any chosen local or remote branch.
