- **spec-board:** a new mod, **Spec Board**, with a **Specs** button in the Dock. It lists the SDD specs (`tasks/prd-*`) of the shown repository and its worktrees, with a status chip, a phase bar and the task progress of each spec. You read and edit the PRD, TechSpec, tasks and reviews, move old specs to the Recycle Bin, and start an agent with `sdd-triar` (new spec) or `sdd-orquestrar-fluxo` (start or continue a spec), here or in a new git worktree. The skill names, the agent and the worktree folder are in Herdr Mods → Settings.
