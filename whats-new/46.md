- **repo-launcher:** Add a folder of another machine (`hc machine ls`) in the settings: pick the machine and type the path. Its repositories show in an **On <machine>** section, and a repository opens in a space on that machine, with the agents installed there. It works with Windows, macOS and Linux machines.
- **repo-launcher:** A switch in the search bar shows all repositories, only the ones on this computer, or only the ones on one machine (`Ctrl+M`).
