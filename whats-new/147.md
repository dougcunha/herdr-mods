- **git-client:** Failed Git actions now open a full, scrollable error dialog instead of a truncated toast, with plain-English explanations and next steps for common Git errors (such as a branch checked out in another worktree, with a button to open it), the complete Git output, and a button to copy the details.
- **git-client:** The Changes tab now supports selecting multiple files at once via inline checkboxes, `Ctrl/Cmd+Click`, `Shift+Click`, or `Ctrl/Cmd+A`, with a bulk action bar and right-click menu to Stage, Unstage, Discard/Delete, Mark resolved, Ignore, Stop tracking, or Copy paths together.
